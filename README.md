# AI Observatory — Brand Category Discovery & AI Validation (sample stage)

Goal (full project): a Category → Brand table of **≥1000 validated, non-duplicate consumer categories**,
each with ≥10 real brands, where each category name is understood correctly by AI.
This repo is the **sample stage** (~60 categories) following the procedure in `JIA_LIU_TASK.md`.

## Procedure

| Step | What | Output | Acceptance |
|---|---|---|---|
| Task 1 | Seed pool = Kantar BrandZ 2025 Global Top 100 + China Top 100 (189 unique brands); assign each a primary category; merge synonymous labels | `data/seed_brands.csv`, `data/categories.csv`, `data/category_merges.csv` | unclassified seeds = 0 |
| Task 2 | For each B2C category, add other major brands found via web research; merge with seeds | `data/category_brands.csv` (+ evidence in `data/raw/task2/`) | ≥10 real brands / category, each with a source URL |
| Task 3 | Ask the AI `What are the best brands for {category}? List 10 brands.` (one fresh chat per category); compare its top 10 with the brand table | `runs/<run_id>/` | Brand Recall@10 ≥ 0.8 |
| Rename | For failed categories: fix alias gaps, or rename the category, and re-test as a new run | `data/category_attempts.csv` | until pass |
| Deliverable | Master table of passed categories | `outputs/master_table.csv` | Category \| Brand \| World/China \| Pass |

**Brand Recall@10** = (number of the AI's top-10 brands that are in the category's brand table) / 10.
Brand names are normalized (case, accents, punctuation, `&`/`and`, trailing Inc/Ltd/Group/.com) and mapped
through `data/brand_aliases.json` (global) + `data/category_aliases.json` (per category), then de-duplicated
before taking the top 10. Fewer than 10 returned brands count as misses.

## Layout

```
JIA_LIU_TASK.md            original task spec
data/
  raw/sources/             Kantar BrandZ 2025 PDFs + pdftotext output + SHA256SUMS (raw, do not edit)
  raw/task2/evidence.jsonl every web page consulted in Task 2 (url, method, brands on page)
  seed_brands.csv          Task 1 seed pool (brand, world_china, raw_label, primary_category_id, source, Kantar category)
  categories.csv           category_id, category_name (name under test), scope (B2C / out_of_scope)
  category_merges.csv      raw_label -> merged category
  category_brands.csv      Task 2 table (generated by scripts/build_category_brands.py)
  brand_aliases.json       global aliases {canonical: [variants]}
  category_aliases.json    per-category aliases {category_id: {canonical: [variants]}}
  category_attempts.csv    Task 3 history, one row per (category, run) — created by `score`
src/observatory/           normalize, metrics, parse (LLM answer -> list), manual (sheet), data (load/check), llm (API stub)
scripts/
  build_category_brands.py curated selection -> category_brands.csv with provenance
  validate.py              check / export / import / query / score / master
runs/<run_id>/             manual_sheet.txt + responses.jsonl (raw AI answers), meta.json, results.csv, summary.json
outputs/                   master_table.csv, category_status.csv, category_results.csv, report_*.pdf
```

## How to run

```bash
python3 -m unittest discover -s tests -v       # unit tests
python3 scripts/build_category_brands.py       # rebuild Task 2 table (fails if any brand lacks a source)
python3 scripts/validate.py check              # Task 1/2 acceptance checks

# Task 3, manual mode (no API key yet):
python3 scripts/validate.py export --run-id r1 # -> runs/r1/manual_sheet.txt
#   fill the 4 header fields; for each category open a NEW ChatGPT Temporary Chat,
#   paste the PROMPT line, paste the full answer under "--- paste answer below ---"
python3 scripts/validate.py import runs/r1     # -> responses.jsonl (warns if <5 brands parsed)
python3 scripts/validate.py score runs/r1      # -> results.csv, summary.json, appends category_attempts.csv
python3 scripts/validate.py master             # -> outputs/master_table.csv

# Rename loop: edit category_name in data/categories.csv, then run a new query/export with --only <ids>

# Task 3, API mode (used for the reported results): OpenRouter, key OPENROUTER_API_KEY in .env (gitignored)
python3 -u scripts/validate.py query --provider openrouter --model deepseek/deepseek-v4-pro --temperature 0 --run-id r1_ds
python3 scripts/validate.py score runs/r1_ds

# Post-validation brand additions (independent evidence)
python3 scripts/verify_candidates.py           # Wikipedia summaries for data/raw/task2/post_validation_candidates.csv
#   manual decisions -> data/raw/task2/post_validation_decisions.csv; then rebuild the table

# Independent checks with the frozen table (not recorded as attempts)
python3 -u scripts/validate.py query --provider openrouter --model qwen/qwen3.7-plus --temperature 0 --run-id r4_qwen_crossmodel
python3 scripts/validate.py score runs/r4_qwen_crossmodel --no-record

# Report numbers and PDFs (needs pandoc + Google Chrome)
python3 scripts/report_stats.py r1_ds r2_ds r3_ds_holdout r4_qwen_crossmodel > outputs/report_stats.json
python3 scripts/report_tables.py > outputs/report_table.md   # also writes category_results.csv, report_appendix.md
sh scripts/report_pdf.sh                                      # docs/report_{en,zh}.md -> outputs/report_{en,zh}.pdf
```
